## 笔记与错题

| 概念或错误 | 原因与修正 |
| --- | --- |
| 综合成绩输出误判为 `(2, 1)` | 权重是一维数组 `(3,)`，所以 `(2, 3) @ (3,) → (2,)`；只有列矩阵权重 `(3, 1)` 才输出 `(2, 1)`。 |
| 将向量元素个数当作模 | `[1, 2]` 与 `[2, 4]` 分量数相同、方向相同，但后者的模是前者的两倍。 |
| 余弦相似度分母少括号 | 应除以两个模的乘积；测试向量的模为 1 时可能掩盖错误。 |
| 已有概率再次做 softmax | 分清 logits 与概率；概率直接用于 `-log(p_target)`。第二个类别的索引是 1。文档已讲清，Notebook 中还需同步修正。 |
| 对批量计算和 axis 不熟悉 | 每行一个样本、每列一个类别；`axis=1` 在每行内部计算，`keepdims=True` 保留列维度以正确广播。需再独立练习。 |
| 梯度正负与更新方向混淆 | 更新公式有减号：正梯度让参数减小，负梯度让参数增大。 |
| 梯度公式最后乘 w | 对 w 求导时，`wx` 的导数是 x，因此 `gradient_w = 2 * error * x`。已修改并验证 loss 下降。 |
| 加偏置后遗漏 gradient_w 中的 x | `gradient_w = 2 * error * x`，`gradient_b = 2 * error`；两者基于同一次前向预测。 |
| 将参数摆动当成损失不稳定 | 学习率 0.2 时 w 在 3 两侧摆动，但摆幅缩小、loss 持续下降；0.3 时本例发散。 |
