## 一、对话总结

这段对话依次讨论了 CS329Z 的先修要求、CS329A 的定位，以及在没有机器学习、深度学习基础的情况下如何学习 Transformer。

学习者已经接触编程、大模型 API、RAG、MCP 和智能体平台，当前明确的短板是机器学习与深度学习理论基础。主要目标是理解大模型与智能体原理，并用于教育智能体研究、CourseMind 和软件项目实训。

核心结论是：先按目标补齐必要基础，再通过小项目进入智能体课程。无需把完整的传统机器学习课程、CS224N 和 CS336 都学完，才能开始学习 Agent。

| 课程 | 对话中的定位 | 本计划中的用途 |
| --- | --- | --- |
| CS224N | NLP 与深度学习基础 | 选学神经网络、Transformer、预训练、后训练及 RAG 等相关内容 |
| CS224U | 语言理解、检索与评测 | 按需补充 RAG 和评测知识 |
| CS224V | Agentic AI | 按需补充工具使用、知识推理和长程任务背景 |
| CS336 | 从零构建与训练语言模型 | 后续有模型训练或系统优化需求时再深入 |
| CS329Z | Engineering AI Agents | 学习 Agent Runtime、工具、记忆、检索和系统评测 |
| CS329A | Self-Improving AI Agents | 学习采样、Verifier、搜索、反馈修正与推理时计算扩展 |

对话记录中，CS329Z 的先修要求被概括为 CS224N、CS224U、CS224V、CS336 中任意一门或等价 NLP 背景；CS329A 被概括为 CS224N 或 CS229S，并要求熟练使用 Python 和大模型 API。这里保留为对话摘要，未重新核验最新学期要求；精选学习路线也不等同于满足正式选课资格。

两门目标课分别回答：CS329Z 如何把 Agent 做成可靠的软件系统；CS329A 如何通过候选生成、评估和反馈改进 Agent 表现。科研价值上可重点关注 CS329A，实际学习时先完成一个可评测的小型 Agent，会更便于开展后续实验。

## 二、学习目标与范围

基础阶段结束后，应达到两个必要目标：能够用自己的话解释 Transformer 和 GPT 的基本工作过程；能够读懂简化的 Attention 代码并判断矩阵维度。实现并训练一个 mini Transformer 是进阶练习，可以帮助巩固理解，但不作为开始 Agent 学习的硬性门槛。

优先学习：向量与矩阵、点积与矩阵乘法、概率分布、softmax、交叉熵、梯度下降、线性层与激活函数、token 与 embedding、Attention、Transformer Block、GPT 与自回归生成。

暂缓学习：复杂矩阵求导、特征值与 SVD 的深入推导、完整传统机器学习算法体系、分布式训练和 GPU 优化。遇到实际问题时再补充。反向传播先理解链式法则与梯度传播的作用，再逐步练习推导。

学习顺序：**最小数学与神经网络 → Attention → Transformer → GPT → Mini Agent 与评测 → 自改进 Agent 实验。**

## 三、四周基础学习计划

原对话建议用约 4 周建立基础。以下练习和验收标准为整理时补充。默认每周投入 6～8 小时：分成 4 次学习，每次 60～90 分钟，再安排一次复盘。时间不足时可把每周内容拆成两周，按掌握程度推进。

### 第 1 周：最小数学与神经网络

**学习内容**

- 标量、向量、矩阵、转置、点积、矩阵乘法和维度检查。
- 概率分布、条件概率、log、softmax 和交叉熵的直觉。
- 线性层、ReLU / GELU、loss、梯度下降与反向传播的基本作用。

**学习与练习顺序**

1. 用 NumPy 创建向量和矩阵，计算点积、矩阵乘法与余弦相似度。
2. 手算一组简单分数的 softmax，观察概率之和为何为 1。
3. 读懂一个简单 MLP 的前向计算，标注每层输入和输出维度。
4. 用小型示例观察参数更新与 loss 变化，理解学习率的作用。

**产出与验收**

完成一份数学基础 Notebook 和一张训练循环图。能解释“前向预测 → loss → 反向传播 → 参数更新”，并独立判断矩阵能否相乘。若矩阵乘法仍不熟练，先补练习，再进入 QKV。

### 第 2 周：Token、Embedding 与 Self-Attention

**学习内容**

- tokenization、token ID、embedding 与序列。
- Q、K、V 的角色和可学习投影矩阵。
- scaled dot-product attention 与按行 softmax。

**核心公式**

```text
Q = XWq，K = XWk，V = XWv
Attention(Q, K, V) = softmax(QKᵀ / √d_k)V
```

Q 与 K 的点积产生注意力分数，softmax 将分数转为权重，再用权重对 V 加权求和。搜索类比可以帮助入门，但 QKV 本质上是学习得到的向量表示。

**学习与练习顺序**

1. 把一句短文本拆成 token，解释 token ID 与向量表示的区别。
2. 用 3～4 个 token 的简化向量构造 X，并标注 Q、K、V 的维度。
3. 用 Python / NumPy 逐步计算分数、缩放、权重和输出。
4. 修改一个输入向量，比较注意力权重和输出变化。

**产出与验收**

完成一个可运行的 Attention Notebook，展示各步矩阵形状与数值。能解释为何乘 K 的转置、为何除以 √d_k、为何最后乘 V；能检查每行权重之和接近 1。这是四周计划的重点。

### 第 3 周：Transformer Block

**学习内容**

- multi-head attention、位置编码或位置表示。
- FFN、残差连接和 LayerNorm。
- 一个 Transformer Block 的数据流。

**学习与练习顺序**

1. 理解多头如何使用不同投影处理表示；不要把每个头固定理解为某一种语法功能。
2. 比较“我喜欢你”和“你喜欢我”，理解为什么需要位置信息。
3. 阅读简化的 PyTorch Block，标注张量形状。
4. 画出 Block 结构，解释 Attention 如何交换 token 信息、FFN 如何加工各位置的表示。

**产出与验收**

完成一张结构图和一份带注释的 Block 示例。能解释残差与归一化的作用，并说明实际模型可能采用不同的 LayerNorm 位置。训练这个 Block 可作为进阶练习。

### 第 4 周：GPT 与大模型训练、生成概念

**学习内容**

- decoder-only 架构、causal mask、next-token prediction。
- 自回归生成、temperature 与采样。
- pretraining、SFT、RLHF / DPO 的目标差异。
- reasoning model 与推理时计算的初步概念。

**学习与练习顺序**

1. 画出“token → embedding 与位置信息 → 多个 Block → 输出 logits → 概率与采样”的流程。
2. 用一个短序列说明 causal mask 为什么阻止访问未来 token。
3. 对比训练中预测下一 token 和生成中逐步追加 token 的过程。
4. 整理预训练、SFT、RLHF 和 DPO 的概念对照表；先理解目标，不要求实现训练算法。
5. 可选：在小型文本数据上训练一个 mini GPT，记录 loss 与生成样例。

**产出与验收**

完成一份 GPT 工作原理说明。能解释 causal mask、自回归生成、训练与推理的区别，以及 temperature 为什么影响采样。若能解释和读懂代码，即可开始后续 Agent 学习，不必等待 mini GPT 训练成功。

## 四、基础完成后的课程衔接

2026 年 10 月 8 日补充：[Agent 课程学习计划](Agent课程学习计划.md)将 CMU 11-768 与 CS329Z 组合为第 5～12 周的具体安排，包含公开视频、实践任务、评测与验收标准。基础阶段之后优先按该计划推进；以下阶段说明保留作为总体路线参考。

以下是基于对话补充的建议安排，不是原对话确定的课程周期。每个阶段约 1～2 周，可根据课程作业难度延长。

### 阶段 A：写一个 Mini Agent，衔接 CS329Z

通过底层大模型 API 实现“模型请求 → 工具调用 → 工具结果 → 模型继续”的循环，再逐步加入检索、记忆和日志。第一版保持范围小：LLM Client、Agent Loop、Tool Registry、一个检索工具和一个简单工具即可。

需理解的重点：消息格式、工具参数、状态、停止条件、最大步数、超时与异常处理。后续再扩展文件或终端工具，并设置明确的操作范围。

**验收标准：**能查看完整执行轨迹；能处理工具失败和非法参数；不会无限循环；能解释每次调用如何影响下一步决策。MCP 可在之后接入，用于理解工具协议与 Agent 决策循环的分工。

### 阶段 B：建立评测，继续 CS329Z

围绕熟悉的教学资料或课程问答，整理 20～30 个固定任务，包含直接问答、检索、多步推理、信息不足和工具失败情况。先写规则或程序评分，再考虑 LLM judge，并人工抽查评分是否可靠。

记录任务成功率、引用与证据质量、工具调用成功率、时延、token 用量或成本，以及主要失败类型。将检索失败、推理失败、工具失败、停止条件问题和评分错误分开分析。

**产出：**任务集、评分脚本、一次基线评测报告。使用固定数据比较改动前后的表现；用于调参的任务与最终测试任务尽量分开。

### 阶段 C：做自改进实验，衔接 CS329A

在同一个任务集上逐步比较：一次生成、多个候选、majority voting（适合答案可归一化的任务）、Best-of-N、Verifier / Critic，以及反馈后修订。继续学习 self-consistency、搜索、reflection 和 test-time compute scaling。

**实验问题：**改进是否来自更好的方法，还是仅来自更多调用？Verifier 是否能可靠选择？反馈修订是否也会把正确答案改错？

**产出：**一份比较报告，同时展示质量、成本和时延。尽量设置相近计算预算的对照；若研究多智能体教育资源生成，再比较单 Agent、增加采样次数和多角色协作，避免直接把角色数量等同于效果提升。

## 五、每周复盘与进入课程的判断

每周复盘回答四个问题：本周能独立解释什么？能独立运行或修改什么代码？最常见的错误是什么？下周必须先补哪一项？遇到不会的公式，优先追踪变量含义与矩阵维度，再补推导。

进入 CS329Z 前，检查自己能否调用 API、实现基本工具循环、说明 RAG 流程、记录执行轨迹，并为任务定义成功标准。进入 CS329A 前，再检查是否理解采样、候选选择、Verifier 与反馈修订，并能设计包含成本对照的小实验。

学习材料按“直觉演示 → 简化代码 → 必要数学 → 小实验 → 论文”的顺序使用。CS224N 作为按需查询的基础材料；不把完成整门课作为开始目标课程的门槛。涉及正式课程先修资格时，以当期官方要求为准。
