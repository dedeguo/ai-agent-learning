# 第四课：修改输入，观察 Attention

保持投影参数不变，把 X 的第三行第一维增加 1。运行 `04_attention_experiments`，先记录预测，再查看差值。

追踪变化：

1. Q、K、V 的第三行可能改变，具体取决于投影参数。
2. 第三行 Q 改变，会影响分数第三行；第三行 K 改变，会影响分数第三列。
3. 某一行只改变一个分数，softmax 也可能改变该行所有权重，因为它们共享分母。
4. V 的第三行改变，会影响读取该位置的输出；A 的变化也会影响输出，因此其他位置的输出可能一起改变。

对照实验：

- 只改 V、保持 Q 和 K：A 应不变，输出可以改变。
- 只改 Q、保持 K 和 V：只有对应查询行的分数、权重和输出可能改变。
- 对每行分数加同一个常数：softmax 应不变。

前两个是人为隔离中间变量的实验，实际修改 X 时 Q、K、V 会一起通过投影重新计算。

最后独立写出一次 Attention 前向计算，再用脚本核对：形状正确、各行权重和为 1、输出等于对 V 的加权求和。不要求本周实现训练或多头注意力。
