# 第二课：从 X 到 Q、K、V

第一周的线性层，现在对每个 token 应用三组不同参数：

```text
Q = X @ Wq
K = X @ Wk
V = X @ Wv
```

本课省略偏置。投影矩阵是可学习参数，Q、K、V 是当前输入和参数产生的中间结果。

| 变量 | 形状 | 用途 |
| --- | --- | --- |
| X | (n, d_model) | 各 token 的输入表示 |
| Wq、Wk | (d_model, d_k) | 得到用于匹配的表示 |
| Wv | (d_model, d_v) | 得到用于传递的内容 |
| Q、K | (n, d_k) | 查询与键 |
| V | (n, d_v) | 值 |

Q 可理解为当前位置“要找什么信息”的表示，K 是各位置“如何被匹配”的表示，V 是最终混合的内容。这是入门类比；这些向量由训练学习，不是人工填写的检索字段。

Self-Attention 中三者来自同一个 X，投影参数可以不同。各位置共享同一套 Wq、Wk、Wv，并不是每个 token 有自己的投影矩阵。

运行 `02_qkv` 实验：`n=3, d_model=4, d_k=2, d_v=3`。有意令 `d_v` 与 `d_k` 不同，观察输出形状。先手算 Q 的第一行，再核对代码。

练习：X 为 `(4, 6)`，Wq 与 Wk 为 `(6, 2)`，Wv 为 `(6, 5)`，Q、K、V 分别是什么形状？

答案：`(4, 2)`、`(4, 2)`、`(4, 5)`。Q 与 K 的最后一维必须一致才能做点积，V 的最后一维可以不同。
