# 第二课：概率、softmax 与损失函数

学习目标：区分模型分数与概率，解释 softmax 如何转换分数，以及损失函数如何评价预测。

## 1. 概率与概率分布

概率用 0 到 1 之间的数字表示一个事件发生的可能性：0 表示不可能，1 表示必然，0.5 表示 50%。

当 A、B、C 是互斥且覆盖全部情况的三个选项时，它们的概率组成一个分布：

```text
[P(A), P(B), P(C)] = [0.1, 0.8, 0.1]
```

每个概率非负，三个概率相加为 1。这两个约束针对完整的概率分布；不能把任意几个事件的概率都要求相加为 1。

模型输出的概率表示模型的预测倾向，不一定等于实际正确率。例如，模型输出 0.8，并不能单凭这个数字保证它在类似问题上有 80% 的正确率。

## 2. 模型分数与概率的区别

模型通常先输出一组分数，称为 logits，例如 `[2, 1, 0]`。

分数可以是负数，也不要求总和为 1。2 分不是 200% 的概率，0 分也不代表不可能。softmax 的作用是把这组分数转换成一个概率分布。

| 数据含义 | 示例 | 计算本课的分类损失前是否需要 softmax |
| --- | --- | --- |
| 模型分数（logits） | `[2, 1, 0]` | 需要先转换为概率，或使用直接接收 logits 的损失实现 |
| 已有的概率分布 | `[0.1, 0.8, 0.1]` | 不需要再次做 softmax |

是否需要 softmax 取决于数据的含义，不能只看数值大小或总和。

## 3. softmax：指数与归一化

对于第 i 个选项的分数 z_i：

```text
p_i = exp(z_i) / Σ_j exp(z_j)
```

分两步理解：

1. 对每个分数取指数，得到正权重。指数函数保持大小顺序，即分数越大，权重越大。
2. 每个权重除以总权重，得到它在总量中的占比。

以 `[2, 1, 0]` 为例：

```text
分数：        [2,          1,          0]
指数权重：    [7.3890561,  2.71828183, 1]
权重总和：    11.10733793
概率：        [0.66524096, 0.24472847, 0.09003057]
概率总和：    1
```

直接把分数除以分数之和无法适用于一般情况：分数可能为负，总和也可能为 0。softmax 通过指数得到正权重，再归一化。

### 三个重要性质

**分数相同，概率相同。** `[0, 0]` 的结果是 `[0.5, 0.5]`；`[2, 2, 2]` 的结果是 `[1/3, 1/3, 1/3]`。

**相对其他选项的分数越高，分配的概率越大。** 保持其他分数不变，提高一个选项的分数，会提高它的概率：

| 分数 | softmax 概率 |
| --- | --- |
| `[1, 0]` | 约 `[0.7311, 0.2689]` |
| `[2, 0]` | 约 `[0.8808, 0.1192]` |

**所有分数同时加上同一个常数，概率不变。** `[2, 0]` 与 `[12, 10]` 得到相同概率，因为分子和分母都乘以同一个 `exp(10)`，这个因子会约掉。

一个选项的概率取决于所有选项的分数。例如 A 都是 2 分，但 `[2, 1, 0]` 中 A 的概率约为 66.5%，`[2, 2, 2]` 中约为 33.3%。

### NumPy 实现

```python
import numpy as np

def softmax(scores):
    """本课使用的一维分数向量的 softmax。"""
    scores = np.asarray(scores, dtype=float)
    weights = np.exp(scores - scores.max())
    return weights / weights.sum()

probabilities = softmax([2, 1, 0])
print(probabilities)
print(probabilities.sum())  # 约为 1
```

减去最大分数不会改变概率，同时避免对很大的正数取指数导致溢出。浮点计算可能产生微小误差，比较数值时可使用 `np.isclose()`。

## 4. 自然对数 log

自然对数 `ln` 是指数函数 `exp` 的反函数，NumPy 中使用 `np.log()`：

```python
print(np.log(np.exp(2.0)))  # 约为 2
```

对于 0 < p ≤ 1，`ln(p)` 不大于 0，所以 `-ln(p)` 不小于 0。p 越接近 1，`-ln(p)` 越接近 0；p 越接近 0，`-ln(p)` 越大。

## 5. 损失函数：评价预测的计算规则

损失函数（loss function）根据预测与真实答案计算一个数值，这个数值叫损失（loss）。训练希望通过调整模型参数，让所选损失下降。

不同任务需要不同的评价规则。损失是训练目标，也需要配合准确率等指标评价实际表现。

### 数值预测：平方误差

```text
loss = (预测值 - 真实值)²

真实成绩为 80：
预测 70 → loss = 100
预测 78 → loss = 4
```

预测越接近真实值，平方误差越小。多个样本的平方误差取平均，得到均方误差（MSE）。

### 单标签分类：交叉熵

对本课的单标签分类，真实标签只有一个正确类别。单个样本的交叉熵简化为：

```text
loss = -ln(p_target)
```

`p_target` 是模型给真实类别分配的概率，而不是模型输出中的最大概率。

更一般的表达式为 `-Σ_i y_i ln(p_i)`。当真实标签是 one-hot 向量，例如 `[0, 1, 0]` 时，只有真实类别的那一项留下来，因此得到 `-ln(p_target)`。

| 给真实类别的概率 | 交叉熵损失（约） |
| --- | --- |
| 0.9 | 0.1054 |
| 0.8 | 0.2231 |
| 0.5 | 0.6931 |
| 0.4 | 0.9163 |
| 0.2 | 1.6094 |
| 0.1 | 2.3026 |

给真实答案的概率越低，损失越大。两个模型即使都选对了，也可能有不同的损失。

## 6. 本次学习中的例子与易错点

### 例子一：固定预测，比较不同真实标签

```python
p = softmax([2, 1, 0])
print(-np.log(p[0]))  # 第一项是真实类别：约 0.4076
print(-np.log(p[2]))  # 第三项是真实类别：约 2.4076
```

这里切换标签是为了理解公式。实际训练的真实标签由数据提供，不能为了减小 loss 随意修改标签。

### 例子二：真实答案是第二项，比较两个模型

```python
a = np.array([0.1, 0.8, 0.1])
b = np.array([0.3, 0.4, 0.3])
target = 1  # Python 索引从 0 开始，第二项的索引是 1

print(-np.log(a[target]))  # 约 0.2231
print(-np.log(b[target]))  # 约 0.9163
```

模型 A 给真实类别的概率更高，因此损失更小。

本次练习中出现的两个易错点：

- 将已有概率再次做 softmax，会改变原来的概率分布。
- 第二个选项使用索引 `1`，第一个选项才是索引 `0`。

这些示例适合手算与入门。极端分数下，softmax 的某些概率可能在浮点计算中变成 0，直接取 log 会得到无穷大；实际训练通常使用数值稳定、直接接收 logits 的交叉熵实现，并按其输入约定传值。

## 7. 各概念如何连接

```text
输入 → 模型 → 分数（logits） → softmax → 预测概率
                                            ↓
真实标签 ───────────────────────────────→ 损失函数
                                            ↓
                                         loss 数值
                                            ↓
                           后续学习：反向传播与参数更新
```

softmax 负责转换分数，损失函数负责评价预测。损失函数本身不会更新参数；更新参数需要梯度与优化方法。
