# 第三课：MLP 前向计算

学习目标：理解线性层与 ReLU，手算一个简单 MLP，并追踪单样本和批量计算的形状。

## 1. 前向计算是什么

MLP（多层感知机）由线性层与非线性激活函数组成。输入依次经过这些运算，得到模型输出，这个过程叫前向计算。

本课使用一个隐藏层、两个输出类别的 MLP：

```text
输入 → 线性层 1 → ReLU → 线性层 2 → 分数（logits）
                                             ↓ softmax
                                          预测概率
                                             ↓ 结合真实标签
                                            loss
```

前向计算使用当前参数进行预测。参数更新是后续梯度下降课程的内容。

## 2. 线性层：权重与偏置

```text
z = x @ W + b
```

- `x` 是输入特征。
- `W` 是权重矩阵，每一列对应一个输出的权重。
- `b` 是偏置，为每个输出提供不依赖输入的基础值。
- `z` 是计算结果，不一定是概率。

严格说，加上偏置后是仿射变换，深度学习中习惯称它为线性层。权重和偏置都是可训练参数。

沿用综合成绩的例子：

```python
import numpy as np

x = np.array([80, 90, 70])
w = np.array([0.5, 0.3, 0.2])
b = 5.0
print(x @ w + b)  # 86.0
```

多个输出可以一起计算：

```python
x = np.array([1.0, 2.0, 3.0])
W = np.array([
    [1.0,  0.0],
    [0.0,  1.0],
    [1.0, -1.0],
])
b = np.array([0.5, 1.0])
z = x @ W + b
print(z)  # [4.5, 0.0]
```

形状变化：`(3,) @ (3, 2) + (2,) → (2,)`。

## 3. ReLU：逐元素的激活函数

```text
ReLU(z) = max(0, z)
```

负数变成 0，正数保留，0 仍为 0：

```python
z = np.array([-3.0, 2.0, -1.0, 5.0])
h = np.maximum(0, z)
print(h)  # [0., 2., 0., 5.]
```

ReLU 不改变形状。它为网络引入非线性；如果只有线性层，无论叠多少层，都可以合并成一个线性层，无法因此表达更复杂的非线性关系。

## 4. 手算一个完整 MLP

```python
x = np.array([1.0, 2.0])

W1 = np.array([
    [1.0, -1.0, 0.0],
    [1.0,  0.0, 1.0],
])
b1 = np.array([0.0, 0.0, -3.0])

W2 = np.array([
    [1.0, -1.0],
    [2.0,  1.0],
    [0.0,  1.0],
])
b2 = np.array([0.0, 1.0])

z1 = x @ W1 + b1
h = np.maximum(0, z1)
logits = h @ W2 + b2

print(z1)     # [3., -1., -1.]
print(h)      # [3.,  0.,  0.]
print(logits) # [3., -2.]
```

逐步计算：

```text
z1[0] = 1×1    + 2×1 + 0    =  3
z1[1] = 1×(-1) + 2×0 + 0    = -1
z1[2] = 1×0    + 2×1 + (-3) = -1

ReLU：[3, -1, -1] → [3, 0, 0]

logits[0] = 3×1    + 0×2 + 0×0 + 0 =  3
logits[1] = 3×(-1) + 0×1 + 0×1 + 1 = -2
```

| 变量 | 形状 | 含义 |
| --- | --- | --- |
| `x` | `(2,)` | 一个样本，两个输入特征 |
| `W1` / `b1` | `(2, 3)` / `(3,)` | 第一层参数 |
| `z1` / `h` | `(3,)` / `(3,)` | 三个隐藏单元的计算结果 |
| `W2` / `b2` | `(3, 2)` / `(2,)` | 第二层参数 |
| `logits` | `(2,)` | 两个类别的分数 |

`W1、b1、W2、b2` 是参数；`z1、h、logits` 是当前输入与参数共同产生的中间结果。

## 5. 批量计算：每行一个样本

批量计算把多个输入叠成矩阵，用同一套参数同时处理。对于本课这个 MLP，各行独立执行相同运算，样本之间不会在前向计算中交换信息。

```python
X = np.array([
    [1.0, 2.0],  # 样本 1
    [2.0, 1.0],  # 样本 2
    [3.0, 4.0],  # 样本 3
    [0.0, 1.0],  # 样本 4
])

Z1 = X @ W1 + b1
H = np.maximum(0, Z1)
logits = H @ W2 + b2
print(logits)
# [[ 3., -2.],
#  [ 3., -2.],
#  [ 7., -5.],
#  [ 1.,  0.]]
```

前两个不同输入在这套参数下碰巧输出相同，不意味着它们没有分别计算。

```text
X      (4, 2)  四个样本，每个两个特征
  @ W1 (2, 3)
Z1     (4, 3)
  ↓ ReLU
H      (4, 3)
  @ W2 (3, 2)
logits (4, 2)  四个样本，每个两个类别分数
```

偏置的广播：`X @ W1` 是 `(4, 3)`，`b1` 是 `(3,)`。NumPy 将同一个 `b1` 加到每一行，并不需要手动复制四份。

## 6. axis 与 keepdims：每行做 softmax

二维矩阵中，`axis` 指定沿哪个维度进行归约（例如求和、求最大值）：

| 操作 | 含义 |
| --- | --- |
| `max(axis=1)` | 每行沿列取最大值，每行留下一个结果 |
| `max(axis=0)` | 每列沿行取最大值，每列留下一个结果 |
| `max()` | 整个矩阵取一个最大值 |

用一个两个方向结果不同的例子：

```python
example = np.array([
    [3.0, -2.0],
    [5.0,  4.0],
])
print(example.max(axis=1))  # [3., 5.]：每行最大值
print(example.max(axis=0))  # [5., 4.]：每列最大值
```

`keepdims=True` 保留被归约的维度：

```python
row_max = example.max(axis=1, keepdims=True)
print(row_max)        # [[3.], [5.]]
print(row_max.shape)  # (2, 1)，而不是 (2,)

shifted = example - row_max
print(shifted)        # [[0., -5.], [0., -1.]]
```

广播使第一行的所有元素都减去 3，第二行都减去 5。保留 `(样本数, 1)` 的形状，才能明确地对每行广播；去掉 `keepdims` 可能报形状错误，也可能在方阵中碰巧广播成功却按错误方向计算。

批量 softmax 的完整实现：

```python
def softmax_batch(logits):
    shifted = logits - logits.max(axis=1, keepdims=True)
    weights = np.exp(shifted)
    return weights / weights.sum(axis=1, keepdims=True)

probabilities = softmax_batch(logits)
print(probabilities.shape)        # (4, 2)
print(probabilities.sum(axis=1))  # 约为 [1., 1., 1., 1.]
```

每行是一个样本在两个类别之间的概率分布，因此每行之和为 1。四个样本的整张概率矩阵所有元素之和约为 4。softmax 不改变矩阵形状。

这里减去每行最大值，是为了避免指数溢出；同一行所有分数减去同一个数，不改变该行的 softmax 概率。

## 7. 批量损失：每个样本取自己的真实类别

```python
p = np.array([
    [0.9, 0.1],  # 样本 1
    [0.8, 0.2],  # 样本 2
])
targets = np.array([0, 1])

loss1 = -np.log(p[0, 0])  # 样本 1，真实类别为 0：约 0.1054
loss2 = -np.log(p[1, 1])  # 样本 2，真实类别为 1：约 1.6094
batch_loss = (loss1 + loss2) / 2
print(batch_loss)        # 约 0.8574
```

也可以一次选出每行的真实类别概率：

```python
rows = np.arange(len(targets))
target_probabilities = p[rows, targets]  # [0.9, 0.2]
losses = -np.log(target_probabilities)
print(losses.mean())                   # 约 0.8574
```

若第二个样本给真实类别的概率从 0.2 提高到 0.7，其他条件不变，它的损失会下降，这批样本的平均损失也会下降。

这些概率取 log 的示例用于理解公式。实际训练宜使用数值稳定的交叉熵实现，以避免极小概率导致数值问题；详见[第二课笔记](02_softmax_and_loss.md)。
