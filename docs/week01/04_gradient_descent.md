# 第四课：梯度、学习率与训练循环

目标：解释梯度如何指导更新，观察学习率的影响，并用多个样本训练一个简单模型。

## 1. 训练的四个环节

```mermaid
flowchart LR
    A[输入数据与当前参数] --> B[前向计算：得到预测]
    B --> C[结合真实标签计算 loss]
    C --> D[反向传播：计算参数梯度]
    D --> E[优化器更新参数]
    E --> B
```

实际训练按设定的步数或停止条件结束循环。

本课模型是 `prediction = w * x + b`：`x、y` 是输入和真实标签，`w、b` 是可训练参数。学习率是人为设置的超参数，不由本课训练循环自动学习。

## 2. 梯度：损失对参数的局部变化率

只有一个参数时，梯度就是导数；多个参数时，梯度由损失对各参数的偏导数组成。

它描述在当前位置，参数发生很小变化时，损失变化的方向与快慢。梯度指向局部损失增大的方向，所以梯度下降沿相反方向更新：

```text
新参数 = 旧参数 - 学习率 × 梯度
```

学习率为正时：

| 某个参数的梯度 | 该参数的更新方向 |
| --- | --- |
| 正数 | 减小 |
| 负数 | 增大 |
| 0 | 本次更新不变 |

梯度为 0 不一定代表全局最优；梯度方向正确也不保证任意大小的更新都降低损失。

## 3. 单参数模型与链式法则

固定 `x = 2、y = 6`，先不加偏置：

```text
prediction = wx
loss = (prediction - y)²

loss 对 prediction 的导数 = 2(prediction - y)
prediction 对 w 的导数 = x

loss 对 w 的导数 = 2(prediction - y) × x
```

链式法则将路径上各步的导数相乘。这里梯度最后乘的是输入 `x`，不是参数 `w`。

初始 `w = 1`，学习率为 0.1：

```text
预测 = 2，loss = 16
梯度 = 2 × (2 - 6) × 2 = -16
新 w = 1 - 0.1 × (-16) = 2.6
新预测 = 5.2，新 loss = 0.64
```

如果 `w = 4`，预测为 8，梯度为 `2 × (8 - 6) × 2 = 8`。更新应减小 w，使预测接近 6。

### 可运行的训练循环

```python
import numpy as np

x, y = 2.0, 6.0
w = 1.0
learning_rate = 0.1

for step in range(6):
    prediction = w * x
    loss = (prediction - y) ** 2
    gradient = 2 * (prediction - y) * x
    print(f"{step}: w={w:.6f}, prediction={prediction:.6f}, loss={loss:.6f}")
    w -= learning_rate * gradient
```

打印的是更新前的状态。执行更新后，刚才计算的 loss 不会自动变化；需要用新参数重新做前向计算。

## 4. 学习率：每次更新的幅度

对于上面的单参数例子，从 `w = 1` 开始：

| 学习率 | 参数变化 | 损失变化 |
| --- | --- | --- |
| 0.1 | 从目标的一侧逐步接近 w = 3 | 下降 |
| 0.2 | 在 3 两侧摆动，摆幅缩小 | 下降 |
| 0.3 | 在 3 两侧摆动，摆幅扩大 | 上升，发散 |

学习率 0.2 时：

| 步数 | 更新前 w | loss |
| --- | --- | --- |
| 0 | 1.0000 | 16.0000 |
| 1 | 4.2000 | 5.7600 |
| 2 | 2.2800 | 2.0736 |
| 3 | 3.4320 | 0.746496 |
| 4 | 2.7408 | 0.26873856 |

参数来回变化不等于 loss 来回变化。关键是参数是否越来越接近损失更小的位置。

可选推导：本例梯度为 `8(w - 3)`，因此更新后与目标的距离满足：

```text
新 w - 3 = (1 - 8 × 学习率) × (旧 w - 3)
```

学习率 0.2 时乘数为 -0.6：负号让它越过目标，绝对值小于 1 让距离缩小。0.3 时乘数为 -1.4，距离反而扩大。本例的收敛范围为 `0 < 学习率 < 0.25`，不能将这个范围直接套用到其他模型或损失。

## 5. 加入偏置：反向传播与更新分开

```text
prediction = wx + b
error = prediction - y
loss = error²

gradient_w = 2 × error × x
gradient_b = 2 × error
```

因为预测对 w 的导数是 x，对 b 的导数是 1，两个参数的梯度通常不同。

当 `x = 2、y = 6、w = 1、b = 1` 时：

```text
预测 = 3，error = -3
gradient_w = -12
gradient_b = -6
```

反向传播通过链式法则计算梯度，优化器再用梯度更新参数；它们是两个步骤。在本课的小模型中，我们手写导数，相当于手动完成梯度计算。

```python
x, y = 2.0, 6.0
w, b = 1.0, 1.0
learning_rate = 0.05

for step in range(10):
    prediction = w * x + b
    error = prediction - y
    loss = error ** 2

    gradient_w = 2 * error * x
    gradient_b = 2 * error
    print(f"{step}: w={w:.4f}, b={b:.4f}, loss={loss:.6f}")

    w -= learning_rate * gradient_w
    b -= learning_rate * gradient_b
```

先根据同一次预测算好两个梯度，再更新两个参数。本例学习率为 0.05 时，误差每步变成原来的一半，loss 每步变成原来的四分之一：`9 → 2.25 → 0.5625 → …`。

只有一个样本时，满足 `2w + b = 6` 的参数组合有很多。训练拟合这个样本，不意味着唯一学到了某套参数，也不能说明对其他输入预测正确。

## 6. 多样本训练：平均损失与平均梯度

使用三个样本，共享同一套 w、b：

| x | y |
| --- | --- |
| 1 | 3 |
| 2 | 5 |
| 3 | 7 |

本例的数据规律是 `y = 2x + 1`。训练目标是让三个样本的平均平方误差（MSE）下降：

```text
loss = mean((wx + b - y)²)
gradient_w = mean(2 × error × x)
gradient_b = mean(2 × error)
```

平均损失的导数等于各样本损失导数的平均。不同样本的梯度可能有不同方向，汇总后共同决定共享参数的更新。

```python
x = np.array([1.0, 2.0, 3.0])
y = np.array([3.0, 5.0, 7.0])
w, b = 0.0, 0.0
learning_rate = 0.05

for step in range(1000):
    prediction = w * x + b
    error = prediction - y
    loss = np.mean(error ** 2)

    gradient_w = np.mean(2 * error * x)
    gradient_b = np.mean(2 * error)

    if step % 100 == 0:
        print(f"{step}: w={w:.4f}, b={b:.4f}, loss={loss:.6f}")

    w -= learning_rate * gradient_w
    b -= learning_rate * gradient_b

final_prediction = w * x + b
final_loss = np.mean((final_prediction - y) ** 2)
print("最终参数：", w, b)
print("最终预测：", final_prediction)
print("最终损失：", final_loss)
```

本次实验得到：

```text
w ≈ 2.0000002482
b ≈ 0.9999994359
预测 ≈ [2.99999968, 4.99999993, 7.00000018]
```

有限次迭代与浮点计算会产生微小差异，不必要求参数精确等于整数。这证明模型拟合了这组数据；泛化能力还需要用未参与训练的数据检验。

这里每一步使用全部三个样本，属于全批量梯度下降。后续可将数据分成小批次，每次用一个小批次估计梯度。

## 7. 本次学习的易错点

- **梯度末尾乘错变量：**对 w 求导时，`wx` 的导数是 x，不是 w。
- **梯度正负与更新方向混淆：**更新公式有减号，正梯度让参数减小，负梯度让参数增大。
- **把参数摆动等同于不收敛：**摆幅缩小时，即使参数交替越过目标，loss 也可以持续下降。
- **忽略学习率：**负梯度方向只描述局部变化，步长过大可能让 loss 上升。
- **混用更新前后状态：**所有参数的梯度应基于同一次前向计算，再统一更新。
