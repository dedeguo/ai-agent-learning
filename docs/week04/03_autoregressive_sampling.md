# 第三课：自回归生成与 temperature

生成从提示词开始：模型计算现有序列 → 取最后一个位置的 logits → 采样一个 token → 追加到序列 → 重复，直到生成 `<eos>` 或达到最大生成长度。

训练时后续输入由数据提供；生成时后续输入包含模型自己的输出。每次生成通常不更新模型参数。示例每步重新计算完整上下文，便于观察；实际系统常使用 KV cache 复用已有计算。

```text
p_i = softmax(logits_i / T)    T > 0
```

固定 logits 下，小 T 通常让分布更集中，大 T 让分布更平坦。相等的 logits 不会因此产生差别。temperature 改变采样概率，不直接改变模型知识或保证答案质量。

本课将 `T=0` 约定为直接 argmax（greedy），不实际除以 0。greedy 选择当前最可能的 token，不保证整个序列的联合概率最大。采样则按概率随机抽取；固定随机种子便于复现。

运行第三课：先比较同一组 logits 在 `T=0.3/1/2` 下的分布，再观察模型每次仅追加一个 token。随机模型生成不连贯属于预期现象。top-k/top-p 是额外的候选筛选规则，本课暂不实现。

验收：说明为什么使用最后一行 logits；区分模型前向计算与采样；解释为何一个 token 可能是一个字、词的一部分或其他片段，未必是一整个词。
