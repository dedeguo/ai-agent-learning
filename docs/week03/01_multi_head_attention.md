# 第一课：从一个头到多个头

第二周，一个头计算 `softmax(Q @ K.T / sqrt(d_k)) @ V`。多头注意力让同一份 X 经不同参数得到多组 QKV，各自计算权重和输出，然后拼接、投影。

本课设 n=3、d_model=4、h=2，每头 d_k=d_v=2：

| 步骤 | 形状 |
| --- | --- |
| X | (3, 4) |
| 每头 Wq、Wk、Wv | (4, 2) |
| 每头 Q、K、V | (3, 2) |
| 每头权重 A | (3, 3) |
| 每头输出 | (3, 2) |
| 拼接两个头 | (3, 4) |
| 拼接结果 @ Wo | (3, 4) |

每个头都能访问 X 的全部四维，经自己的投影得到两维表示。不是把输入的前两维给头 1、后两维给头 2。拼接沿特征维进行，不能沿 token 维进行。

Wo 将不同头的输出重新混合，保持 d_model，便于残差相加。常见实现令每头维度等于 d_model/h；这是本课采用的配置，并非数学上唯一可能的配置。

先预测再运行 `01_multi_head_attention`：两个头的权重一定不同吗？答案：不一定，取决于参数和输入；本课不同随机参数通常产生不同权重。头的功能由训练形成，不应预设一个头专门识别主语。

练习：8 个 token，d_model=12，h=3，每头输出、权重矩阵、拼接后的形状是什么？答案：`(8,4)`、`(8,8)`、`(8,12)`。
