# 第二课：为什么需要位置信息

“我 喜欢 你”和“你 喜欢 我”包含相同的 token，顺序改变了含义。没有位置信息、mask 或其他顺序机制的 Self-Attention，输入行重排后，输出也只是相同地重排行。这称为置换等变；并不意味着原始输出矩阵完全相同。

实验先将 X 按 `[2,1,0]` 重排，验证 `MHA(X[order]) ≈ MHA(X)[order]`。再加位置向量：比较 `MHA(X[order]+P)` 与 `MHA(X+P)[order]`。P 绑定当前位置，因此重新排列 token 后，两者一般不同。

本课使用正弦位置编码，偶数通道为 sin，奇数通道为 cos：

```text
P[pos, 2i]   = sin(pos / 10000^(2i/d_model))
P[pos, 2i+1] = cos(pos / 10000^(2i/d_model))
输入表示 = token embedding + P
```

相加不改变 `(n,d_model)` 的形状。位置表示还可以采用可学习向量；RoPE 等方法在注意力计算中引入位置，不都直接加到 embedding 上。

运行 `02_positions`，观察两次最大误差。第一次应接近浮点误差，第二次通常明显非零。正弦编码提供顺序线索，但本实验未训练，不能由此断言模型已经理解句意。
